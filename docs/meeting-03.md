## 확정된 결함

### 치명 (2건 — 둘 다 통합자가 브라우저/런타임에서 직접 재현)

**T3-1. 본문 입력칸이 키보드 트랩이다 — WCAG 2.1.2 (Level A) 위반**
- `js/editor.js:655-676` — `if (e.key === 'Tab') { e.preventDefault(); … }` 에 **탈출 조건이 없다.** Shift 여부와 무관하게 무조건 가로챈다.
- **재현(실측)**: `#fBody`에 포커스 → Tab 3회 → 포커스가 `fBody`에 그대로 머물고 값만 `"abc      "`로 공백이 늘어난다. Shift+Tab도 동일하게 `fBody`에 갇힌다.
- 파급: 키보드만 쓰는 사용자는 본문에 들어간 뒤 **내보내기 버튼조차 누를 수 없다.** DOM상 본문 뒤에 있는 미리보기 안의 `.code-copy`·`.table-wrap[tabindex=0]`도 영영 도달 불가.
- 해법 방향: `Esc`를 "다음 Tab은 포커스 이동" 토글로 쓰는 관행(CodeMirror/Monaco). placeholder(`write.html:216`)에도 한 줄 안내.
- 담당: **frontend-dev-2**

**T3-2. 제목·요약에 큰따옴표를 쓰면 저장할 때마다 백슬래시가 증식한다 — 데이터 손상**
- `js/store.js:638`이 `"` → `\"`로 escape하는데 `js/store.js:67-76 stripQuotes`가 **unescape를 하지 않는다.**
- **재현(실제 `Blog.store` 함수 3회 왕복)**:
  ```
  1회  say "hi"        → 파일 title: "say \"hi\""        → 읽으면 say \"hi\"
  2회  say \"hi\"      → 파일 title: "say \\"hi\\""      → 읽으면 say \\"hi\\"
  3회                                                    → 읽으면 say \\\"hi\\\"
  ```
- 파급: 하이브리드 흐름(불러오기 → 수정 → 내보내기)을 반복할수록 제목이 망가진다. **되돌릴 수 없는 방향으로만 변한다.**
- 담당: **frontend-dev**
