## 디스크

> 컴퓨터의 운영체제, 프로그램, 파일 등의 데이터를 장기간 저장하고 필요할 때 데이터를 읽거나 기록하는 저장장치

**-종류-**

- HDD - 자기적인 방식으로 데이터를 저장하는 저장장치
- SSD - NAND Flash 반도체에 데이터를 저장하는 저장장치

HDD는 회전하는 플래터와 읽기/쓰기 헤드를 이용

SSD는 NAND Flash와 컨트롤러를 이용

---
## 역할

> 데이터 저장 -> 데이터 읽기 -> 데이터 쓰기 -> 운영체제 및 프로그램 저장 -> 파일 저장

-**데이터 저장**-

저장되는 데이터

- 운영체제
- 프로그램
- 실행 파일
- 문서
- 이미지
- 동영상
- 데이터베이스 파일

-**데이터 읽기**-

> 저장장치 -> 데이터 검색 -> 데이터 읽기 -> 운영체제/프로그램으로 전달

-**데이터 쓰기**-

새로운 데이터를 저장해야 하면 저장장치에 쓰기 요청을 전달

> 프로그램 -> 운영체제 -> 저장장치 -> 데이터 기록

-**운영체제 및 프로그램 저장**-

부팅할 때도 저장장치에 저장된 운영체제와 필요한 파일을 읽어 사용함

> 저장장치 -> 운영체제 파일 읽기 -> 시스템 실행

---
## HDD 내부 구조

- 플래터
- 스핀들 모터
- 읽기/쓰기 헤드
- 액추에이터
- 컨트롤러
- 캐시
- 인터페이스

-**플래터**-

HDD에서 실제 데이터를 저장하는 원판 형태의 자기 기록 매체

- 여러 장의 플래터가 하나의 스핀들에 연결되어 함께 회전할 수 있음

-**스핀들 모터**-

플래터를 빠른 속도로 회전시키는 모터

> 스핀들 모터 -> 플래터 회전

-**읽기/쓰기 헤드**-

플래터의 자기 상태를 읽거나 변경하는 장치

- 읽기 - 플래터에 기록된 자기 상태를 읽음
- 쓰기 - 플래터에 새로운 자기 상태를 기록

-**액추에이터**-

읽기/쓰기 헤드를 원하는 트랙 위치로 이동시키는 장치

> 액추에이터 -> 헤드 이동 -> 원하는 트랙 접근

이때 발생하는 대표적인 시간이 Seek Time

- Seek Time - 헤드가 원하는 트랙으로 이동하는 데 걸리는 시간

-**컨트롤러**-

HDD의 전체 동작을 제어하는 전자 회로

-주요 역할-

- 읽기/쓰기 명령 처리
- 헤드와 액추에이터 제어
- 플래터 회전 제어
- 데이터 전송 제어
- 오류 처리
- 호스트와의 통신

-**Cache**-

HDD 내부에서 데이터를 일시적으로 저장하여 읽기/쓰기 작업을 보조하는 영역

> Host -> HDD Cache -> Platter

혹은

> Platter -> HDD Cache -> Host

캐시를 통해 디스크에서 발생하는 일부 읽기/쓰기 작업을 효율적으로 처리할 수 있음

## SSD 내부 구조

> NAND Flash, Controller, Firmware, FTL, ECC, Cache/DRAM

-**NAND Flash**-

SSD에 실제 데이터가 저장되는 반도체 메모리

- 구성요소-
- Cell 
- Page
- Block

**-Cell-**

실제 전하 상태를 이용해 데이터를 저장하는 가장 작은 물리적인 저장 요소

- SLC
- MLC
- TLC
- QLC
- PLC

등으로 구분

-**Page**-

NAND에 데이터를 기록하는 기본 단위

> Data -> Page에 기록

- SSD는 데이터를 일반적으로 Page 단위로 씀

-**Block**-

여러 개의 Page를 묶은 단위

- Write = Page 단위
- Erase = Block 단위

> NAND는 기존 데이터가 존재하는 Page를 다시 쓰는 대신 **해당 영역을 지우고 재사용**하며 **삭제 작업은 Block 단위**로 이루어짐

-**컨트롤러**-

SSD 내부에서 NAND Flash와 호스트 사이의 데이터 이동을 관리하는 핵심 프로세서

-주요 역할-

- 읽기/쓰기 명령 처리
- NAND Flash 제어
- 논리 주소와 물리 주소 매핑
- 오류 검출 및 수정
- Garbage Collection
- Wear Leveling
- 데이터 관리
- 호스트 인터페이스 처리

-**Firmware**-

SSD 컨트롤러가 저장장치를 제어할 수 있도록 규칙과 알고리즘을 구현한 내부 소프트웨어

- Controller = 하드웨어 처리 장치
- Firmware = Controller가 SSD를 관리하도록 만드는 제어 소프트웨어

-**FTL**-

운영체제가 사용하는 논리 주소와 NAND Flash의 실제 물리 위치를 연결하는 계층

> Host LBA -> FTL -> NAND Physical Location

- LBA - 운영체제가 SSD에 데이터를 저장할 때 쓰는 특정 기준

**-ECC-**

SSD에서 NAND Flash에 저장되거나 읽히는 데이터의 오류를 검출하고 수정하기 위한 기술

- SSD 컨트롤러는 ECC 등의 오류 관리 시굴을 사용해 데이터의 신뢰성을 유지

## 데이터 처리 흐름

-HDD 데이터 읽기-

> 프로그램 -> 운영체제 -> 파일 시스템 -> 저장장치 I/O 요청 -> HDD 컨트롤러 -> Actuator -> Read/Write Head -> Platter -> 데이터 읽기 -> 컨트롤러 -> 운영체제 -> 프로그램

-HDD 데이터 쓰기-

> 프로그램 -> 운영체제 -> 저장장치 I/O 요청 -> HDD Controller -> Head 이동 -> Platter 회전 -> 데이터 기록

-SSD 데이터 읽기-

> 프로그램 -> 운영체제 -> 파일 시스템 -> 저장장치 I/O 요청 -> SSD Controller -> FTL -> NAND 위치 확인 -> NAND Page Read -> Controller -> 운영체제 -> 프로그램

-SSD 데이터 쓰기-

> Host LBA -> SSD Controller -> FTL -> Free Page 선택 -> NAND Page Program -> 기존 데이터 Invalid 처리 -> Mapping 정보 변경

## 총 정리 및 핵심 요약

> 디스크 = 운영체제, 프로그램, 파일 등의 데이터를 장기간 저장하고 필요할 때 읽고 쓰는 저장장치

- HDD = 자기 기록 방식의 저장장치
- SSD = NAND Flash 기반의 저장장치

-HDD-

- Platter = 데이터를 저장하는 자기 기록 매체
- Spindle Motor = Platter를 회전
- Read/Write Head = 데이터를 읽고 기록
- Actuator = Head를 원하는 위치로 이동
- Controller = HDD 전체 동작 제어
- Cache = 읽기/쓰기 작업 보조

-SSD-

- NAND Flash = 실제 데이터 저장
- Cell = 데이터를 저장하는 물리적 저장 요소
- Page = NAND의 프로그램 단위
- Block = 여러 Page의 집합이며 Erase 단위
- Controller = SSD 전체 동작 제어
- Firmware = SSD 관리 동작을 수행하는 내부 소프트웨어
- FTL = 논리 주소와 실제 NAND 위치를 매핑
- ECC = 데이터 오류 검출 및 수정

-HDD 전체 흐름-

> 프로그램 -> 운영체제 -> 파일 시스템 -> I/O 요청 -> HDD Controller -> Actuator -> Head -> Platter -> 데이터 -> 운영체제 -> 프로그램

-SSD 전체 흐름-
> 프로그램 -> 운영체제 -> 파일 시스템 -> I/O 요청 -> SSD Controller -> FTL -> NAND -> Page -> 데이터 -> 운영체제 -> 프로그램
