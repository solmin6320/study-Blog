## RAM

> CPU가 현재 실행 중인 프로그램과 그 프로그램이 사용하는 데이터를 빠르게 읽고 쓸 수 있도록 임시로 저장하는 주기억장치

- 일반적인 PM의 RAM은 대부분 DRAM 기반

-**대표적인 DRAM 규격**-

- DDR4
- DDR5
- LPDDR4
- LPDDR5

RAM = 주기억장치
일반적인 PC RAM = DRAM 기반 메모리

---
## 역할

> 프로그램과 데이터를 임시 저장 -> CPU에 데이터 제공 -> 결과 데이터 저장

-**프로그램 실행에 필요한 데이터 저장**-

프로그램이 실행되면 운영체제는 코드와 필요한 데이터를 메모리에 배치함

> 저장장치 -> RAM -> CPU

- 프로그램 코드와 필요한 데이터가 CPU가 접근할 수 있는 메모리 공간으로 들어옴

-**CPU의 데이터 읽기**-

> CPU -> Memory Controller -> DRAM -> 데이터 변환 -> CPU

실제 CPU는 일반적으로 캐시가 존재함

- 즉 메모리 접근이 바로 DRAM까지 내려가는 것이 아님

> CPU -> Cache 확인 -> Cache Miss -> Memory Controller -> DRAM

-**CPU의 데이터 쓰기**-

CPU가 계산한 결과나 프로그램의 상태를 메모리에 저장해야 할 경우 RAM에 데이터를 기록

> CPU -> Memory Controller -> DRAM -> 데이터 저장

-**빠른 임시 작업 공간 제공**-

-CPU가 프로그램을 실행-

- 명령어
- 변수
- 객체
- 스택
- 힙
- 운영체제가 사용하는 데이터

등을 저장하는 공간으로 사용

- RAM은 프로그램이 실행되는 동안 CPU가 사용할 데이터를 담는 작업 공간

## 내부 구조

> RAM Module -> DRAM Chip -> Bank -> Row / Column -> Cell

-**DRAM Cell**-

DRAM에서 데이터를 저장하는 가장 기본적인 단위

-하나의 DRAM Cell-
> Transistor, Capacitor

- Capacitor = 전하를 저장
- Transistor = 해당 Cell의 접근을 제어

> 데이터 저장 -> 시간이 지나며 전하 감소 -> Refresh -> 데이터 유지

-**Row / Column**-

DRAM Cell의 배열 구성

> Row + Column -> 특정 Memory Cell 위치 지정

-**Bank**-

DRAM은 여러 개의 독립적인 Bank로 구성

>DRAM -> Bank 0 | Bank 1 | Bank 2 . . .

- 여러 Bank를 이용하면 메모리 시스템의 병렬성을 높일 수 있음

-**Rank**-

여러 DRAM 칩을 묶어 메모리 모듈에서 하나의 데이터 폭을 제공하도록 구성한 단위

- Bank = 하나의 DRAM 칩 내부의 메모리 배열 단위

- Rank = 메모리 모듈의 여러 DRAM 칩을 하나의 그룹으로 구성한 단위

-**DIMM / Memory Module**-

사용자가 실제 컴퓨터에 장착하는 RAM 모듈

데스크톱

- DIMM

노트북

- SO-DIMM

RAM 16GB - 여러 DRAM Chip이 장착된 메모리 모듈의 전체 용량

-**Memory Controller**-

CPU와 DRAM 사이에서 메모리 접근을 제어하는 하드웨어

-주요 역할-

- 메모리 읽기 요청 처리
- 메모리 쓰기 요청 처리
- DRAM 명령 생성
- 메모리 주소 처리
- 채널 관리
- DRAM 초기화 및 유지 관리

Memory Controller가 CPU 내부에 통합되는 구조

-**Memory Channel**-

CPU의 메모리 컨트롤러와 RAM 사이의 데이터 통신 경로

> CPU Memory Controller -> Channel -> DRAM

- 하나의 시스템은 여러 개의 Memory Channel을 사용할 수 있음

예시 구성
- Single Channel
- Dual Channel
- Quad Channel

## 메모리 접근 흐름

> CPU -> RAM -> 데이터

전체적인 흐름

>CPU -> CPU Cache -> Memory Controller -> Memory Channel -> DRAM -> Bank -> Row / Column -> Cell

-**데이터 쓰기**-

> CPU -> Cache / Memory System -> Memory Controller -> Memory Channel -> DRAM -> 해당 위치에 Data 기록

-**데이터 읽기**-

> CPU -> 메모리 주소 요청 -> Cache 확인 -> Cache Miss -> Memory Controller -> Memory Channel -> DRAM -> 해당 Bank/Row/Column 접근 -> 데이터 변환 -> CPU

-**DRAM 내부 접근**-

> Memory Address -> Bank 선택 -> Row 선택 -> Row 활성화 -> Column 선택 -> Data Read / Write

## 디스크와의 관계

- 디스크 = 데이터를 장기간 저장
- RAM = CPU가 실행 중인 프로그램과 데이터를 작업하기 위해 사용하는 메모리

-흐름-

> SSD / HDD -> RAM -> CPU

-프로그램의 실행 결과나 파일 데이터가 저장-
> CPU / RAM -> 저장장치

- RAM은 디스크의 단순한 복사본이 아님

## 총 정리 및 핵심 요약

> RAM = CPU가 현재 실행 중인 프로그램과 데이터를 빠르게 읽고 쓰기 위해 사용하는 주기억장치

-**RAM 기본 구조**-

- RAM Module
- DRAM Chip
- Bank
- Row / Column
- Cell

-**DRAM Cell**-

- Transistor = Cell 접근 제어
- Capacitor = 전하 저장
- Refresh = 전하 감소에 따른 데이터 유지

--- 

- Bank = DRAM 내부의 메모리 배열 단위
- Rank = 여러 DRAM 칩을 묶은 모듈 단위 
- Memory Channel = CPU의 Memory Controller와 RAM 사이의 데이터 통신 경로
- Memory Controller = CPU와 DRAM 사이의 메모리 접근을 제어
