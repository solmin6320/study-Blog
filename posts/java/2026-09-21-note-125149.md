## 캡슐화
> 객체의 상태를 외부가 마음대로 변경하지 못하게 하고 객체 스스로 자신의 상태를 관리하도록 만드는 것

```Java
class Member {
  private String name;
  private int age;
}

class Member {
 // 외부에서 직접 접근할 수 없는 상태
  private String name;
  
  // 외부에 공개되는 기능
  public String getName() {
      return name;
  }
}

class Member {
  // 같은 패키지 또는 상속 관계에서만 접근 가능
  protected String role;
}
```
핵심 문법:
- private : 외부에서 직접 접근하지 못하게 함
- public : 외부에서 허용된 기능만 사용할 수 있게 한다
- protected : 같은 패키지 또는 상속 관계의 자식 클래스에서 접근 할 수 있음

---

## getter / settter
> 상태를 읽거나 변경하는 메서드

```Java
class Member {

  private String name;
  
  // name의 값을 읽거 반환
  public String getName() {
      return name;
 }

  // 전달받은 값으로 name을 변경
  public void setName(String name) {
        this.name = name;
  }
}
```
핵심 문법:
- setter : 객체의 상태를 읽고 값을 반환
- getter : 외부에서 전달받은 값으로 객체의 상태를 변경

---

## 전체 흐름

> 외부 -> 공개된 메서드 호출 -> 객체 내부의 로직 실행 -> private 상태 접근/변경
---

핵심 정리:
- 캡슐화 : 객체의 내부 상태를 외부에 직접 노출하지 않는 것

- private : 필드에 대한 외부의 직접 접근을 제한

- public : 외부에 필요한 기능만 공개

- protected : 같은 패키지 혹은 상속 관계에서만 공개

- getter : 객체의 상태를 읽고 반환

- setter : 객체의 상태를 변경
