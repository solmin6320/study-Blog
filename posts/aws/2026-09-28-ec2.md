## EC2(Amazon Elastic Compute Cloud)

> AWS 데이터센터의 서버를 사용해서 소프트웨어를 구축하고 호스팅할 수 있도록 제공하는 서비스

EC2 - AWS에서 하나의 서버처럼 사용할 수 있는 컴퓨팅 자원을 만들어주는 서비스

## 전체 구조

**-Instance-**

실제로 실행되고 있는 EC2 가상 서버 한 대
> EC2 -> Instance #1 - Instance #2 - Instance #3 . . .

**-AMI-**

EC2를 어떤 운영체제와 초기 소프트웨어 환경으로 부팅할지를 정의한 이미지

> AMI -> Ubuntu

또는 

> AMI -> Windows

AMI - 이 상태를 기반으로 EC2를 만들라고 정의하는 것

**-EBS-**

EC2에 사용할 수 있는 블록 스토리지 이며 운영체제의 디스크 같은 역할을 함

> EC2 -> EBS -> Disk

**-Network Interface-**

EC2의 네트워크 카드 역할을 하는 가상 장치

> EC2 -> ENI -> Private IP - Network 설정

**-Secutiry Group-**

EC2로 들어오고 나가는 네트워크 트래픽을 통제하는 가상 방화벽

- 22 -> SSH
- 80 -> HTTP
- 443 -> HTTPS
- 8080 -> Spring Boot

같은 규칙을 둘 수 있음

---
## 전체 구조

> AWS 물리 인프라 -> Nitro System / 가상화 계층 -> EC2 Instace -> Guest OS -> Process -> Spring Boot -> JVM Memory

EC2 내부
> CPU, RAM, Disk, Network
= 하나의 컴퓨터처럼 보임

> EC2 -> 커널 -> Process -> JVM -> Spring Boot

---
## 역할

> 애플리케이션을 실행할 서버가 필요하기 때문

EC2가 없다면?
> 내 PC -> Spring Boot

실제 서비스 관점에서
- 항상 켜져 있어야 함
- 인터넷에서 접근할 수 있어야 함
- 충분한 CPU/RAM 이 필요
- 장애나 확장을 매번 고려해야 함

그러므로 AWS의 서버 인프라를 활용함

> AWS -> EC2 -> Spring Boot

---
## 전체 흐름

1. 개발자가 EC2 생성 요청

> 개발자 -> AWS Console / CLI / SDK -> AWS API -> EC2 Control Plane

2. AMI 선택

> OS / 초기 환경

3. Instance Type 선택

> Instance Type -> vCPU, Memory, Network capability

AMI - 어떤 환경으로 시작할지

Instance Type - 어느 정도의 컴퓨팅 자원을 사용할지

4. AWS가 EC2 Instance를 생성

> AWS Region -> Availability Zone -> AWS Compute Infrastructure -> EC2 Instance

5. Storage와 Network 연결

EBS 연결 - 디스크 역할

Network Interface - VPC 네트워크에 연결

> EC2 -> CPU - RAM - ENI - EBS

6. OS 부팅

> EC2 -> AMI 기반 OS -> 커널 -> System Processes

---
## 핵심 정리 및 배운점

EC2 - AWS에서 CPU, 메모리, 네트워크, 스토리지 등의 컴퓨팅 자원을 갖춘 가상 서버를 생성하고 사용하는 서비스

AMI - 서버를 어떤 OS/환경으로 시작할지 정의한 이미지

Instance Type - CPU / Memory / Network 등의 컴퓨팅 자원 규격

Instance - 실제 실행 중인 가상 서버

EBS - EC2에서 사용하는 블록 스토리지

ENI - EC2의 가상 네트워크 인터페이스

Security Group - EC2 네트워크 접근을 제어하는 가상 방화벽

EC2를 생성하는 흐름

> 개발자 -> AWS Console / CLI / SDK -> AWS API -> Control Plane -> AMI + Instance Type -> EC2 Instance 생성 -> EBS / ENI 연결 -> OS Boot

EC2 - 가상 서버(컴퓨팅 환경)
