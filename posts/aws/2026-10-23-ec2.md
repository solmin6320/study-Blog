## VPC

> AWS 리소스를 **논리적으로 격리된 가상 네트워크 안에 배치**하고 리소스 간의 **네트워크 통신과 연결 경로를 구성할 수 있도록 제공**하는 서비스

VPC = AWS 인프라 위에서 논리적으로 격리된 가상 네트워크

---
## 전체 구조

AWS 리소스를 배치하고 네트워크 통신 경로를 구성하는 가상 네트워크

> VPC -> IP 주소 범위 -> Subnet -> AWS 리소스

- VPC 안에 여러 서브넷을 구성하여 웹 서버, 애플리케이션 서버 등을 구분할 수 있음

-**CIDR**-

VPC 에서 사용할 IP 주소의 범위를 나타내는 표기법

> VPC -> 10.0.0.0/16

- 10.0.0.0/16은 IPv4 주소를 표현하는 네트워크 범위
