## PCB (Process Control Block)

> 운영체제가 프로세스를 관리하기 위해 유지하는 정보들을 담은 자료 구조

-**PCB가 없으면**-
- 운영체제가 어떤 프로세스가 실행 중인지 구분하기 어려움
- 프로세스의 실행 상태를 체계적으로 관리하기 어려움
- 프로세스가 사용하는 메모리와 자원을 추적하기 어려움

-**PCB에 저장되는 주요 정보**-

1. Process ID(PID)
 - 프로세스를 식별하기 위한 고유 식별자
 - 운영체제가 여러 프로세스를 구분하고 관리하는 데 사용

2. Process State (프로세스 상태)
 - 현재 프로세스가 어떤 상태인지 나타내는 정보
 - Ready, Running, Waiting, Terminated 등이 있음

3. CPU Context (CPU 실행 상태)
 - 프로그램 카운터(PC)
 - CPU 레지스터
 - 스택 포인터(SP)

4. CPU Scheduling Information (CPU 스케줄링 정보)
 - 프로세스의 우선순위
 - 스케줄링 정책
 - CPU 실행과 관련된 관리 정보
 
---
## 메모리 구조

> 운영체제 Kernel -> PCB에 해당하는 관리 자료구조 -> 프로세스 관리

-**메모리 내부**-

운영체제의 커널은 프로세스 관리에 필요한 정보를 **커널 메모리 영역에서 관리**

-**User Space (사용자 영역)**-
- Code: 프로그램의 실행 명령어
- Data: 전역 변수 및 정적 변수
- Heap: 동적 메모리 할당 영역
- Stack: 함수 호출 및 지역 변수 등을 관리하는 영역

-**Kernel Space (커널 영역)-**
- 프로세스 관리 자료구조
- 메모리 관리 자료구조
- 파일 및 I/O 관련 관리 자료구조
- CPU 스케줄링 관련 자료구조

---
## 역할

> 운영체제가 여러 프로세스의 상태와 자원을 추적하고, 실행 및 관리를 수행할 수 있도록 정보를 유지하는 것

1. 프로세스 식별 및 관리
 - PID 등을 통해 프로세스를 구분
 - 프로세스의 상태와 생명주기를 관리

2. 메모리 관리 지원
 - 프로세스가 사용하는 메모리 주소 공간을 추적
 - 관련 메모리 관리 자료구조와 연결
 
3. 프로세스 자원 관리
 - 파일, I/O, 시그널 및 권한 등과 관련된 자원을 관리
 - 프로세스가 사용하는 시스템 자원을 추적

## 전체 흐름 (리눅스 기준)

-**프로세스 생성**-
> 프로그램 실행 요청 -> Kernel -> 프로세스 생성 및 관리 자료구조와 준비

-**PCB에 해당하는 관리 정보 구성**-

> task_struct 생성 -> PID 및 작업 상태 등 관리 정보 설정

-**메모리 및 자원 연결**-
> task_struct -> Kernel Stack / 기타 관련 커널 자료구조

-**프로세스 실행 준비**-
> 프로세스 상태 및 스케줄링 정보 관리 -> 실행 가능한 작업으로 등록

-**CPU 스케줄링**-
> Scheduler -> 관리 중인 작업의 스케줄링 정보 확인 -> 실행할 작업 선택

-**컨텍스트 스위칭**-
> 기존 작업의 실행 상태 보존 -> 다음 작업의 실행 상태 복원 -> CPU 실행 대상 전환

-**프로세스 종료**-

> 종료 상태 기록 -> 프로세스 자원 정리 -> 관련 관리 자료구조 해제

-**전체 구조**-

> Process 생성 -> Kernel -> task_struct 생성 및 초기화 -> 메모리 및 자원 연결 -> Scheduler가 작업 선택 -> Context Switching -> Process 실행

## 핵심 정리 및 배운점
PCB - 운영체제가 프로세스를 관리하기 위해 유지하는 정보들을 담은 자료구조

PID - 프로세스를 식별하기 위한 ID

Process State - 프로세스의 현재 상태

CPU Scheduling Information - CPU 할당과 관련된 스케줄링 정보

Memory Management Information - 프로세스의 메모리 주소 공간과 관련된 정보

CPU Context - 프로세스의 실행을 이어가기 위해 필요한 CPU 실행 상태

task_struct - Linux에서 개별 작업(Task)을 관리하는 핵심 커널 자료구조

mm_struct - Linux에서 메모리 주소 공간을 관리하는 자료구조


-**PCB의 핵심 역할**-

- 운영체제가 프로세스를 식별하고 관리할 수 있도록 함
- 프로세스 상태와 스케줄링 정보를 유지
- 프로세스가 사용하는 메모리와 자원을 추적
- CPU 스케줄링과 컨텍스트 스위칭을 지원
